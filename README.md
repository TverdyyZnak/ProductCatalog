# ProductCatalog Test

Реализовано:
  - Back-end
  - Front-end (Базовый, для проверки основных функций)
  - Dockerfile

## Инструкция по запуску через Docker
  1. Открыть консоль и введите ```git clone https://github.com/TverdyyZnak/ProductCatalog.git```
  2. Открыть корневую папку ProductCatalog, откройте консоль и введите ```docker compose up -d --build```
  3. Открыть браузер и:
    - перейти на сайт по ссылке ```http://localhost:8081``` (реализация Front-end)
    - перейти на сайт по ссылке ```http://localhost:8080/index.html``` (swagger)

## Примечание
  - Папка Migrations с БД не добавлена в gitignore СПЕЦИАЛЬНО. При необходимости можно воссоздать архитектуру БД отдельно от проекта
  - Проект написан по принципам "Чистой архитектуры". Слой ProductCatalog - это Presentation.
  - Некоторые решения были упрощены для тестового задания (В коде есть комментарии в таких местах)
  - Аутентификации и авторизации реализована через JWT, которые находятся в куки ("JCook")

## Вход в систему
  - В системе реализовано разделение на роли (Admin, ProUser, User)
  - Чтобы войти в аккаунт, необходимо ввести логин и пароль одного из заранее созданного пользователя

 Admin
   - логин: Admin123
   - пароль: Admin123

 ProUser
   - логин: ProUser1
   - пароль: ProUser1

 User
   - логин: User1234
   - пароль: User1234
